# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through a
[private GitHub security advisory](https://github.com/kelvin0520lcy/resolve/security/advisories/new).
This keeps the report confidential while it is investigated.

Include the affected route or feature, reproduction steps, and the impact you
observed. Do not include real passwords, Firebase credentials, ID tokens,
private reflections, or another person’s data.

For ordinary bugs that do not expose data or bypass a security boundary, use
the public issue tracker instead.

## Supported version

Resolve! is currently a public beta. Security fixes are applied to the current
`main` branch and the active production deployment.
